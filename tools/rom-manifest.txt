# ROM and disk images the emulator needs, none of which are in the repo.

# One entry per line: destination path, sha256, source URL ("-" if the image
# has no public home and has to be supplied by hand). A URL ending in "#member"
# names a file inside a zip. tools/fetch-roms.py reads this file; it copies
# from the local archive named by $EMU_ROM_ARCHIVE first, falls back to the
# URL, and verifies the hash either way.
#

# "make -C test ray703", which writes them to roms/703.
