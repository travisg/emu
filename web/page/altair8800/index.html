MITS Altair 8800

The 1975 Intel 8080 kit computer, emulated, with Altair BASIC on its paper tape. Its front panel above, its teletype below.

8K BASIC 4.0, off paper tape

Operating it

  • The machine powers on stopped, WAIT lit, with MITS's bootstrap loader keyed into the bottom of memory and BASIC's tape in the reader. Press RUN (the bottom of STOP/RUN) and the tape loads in about a second.
  • Click the paper, then type. BASIC asks MEMORY SIZE?, TERMINAL WIDTH? and WANT SIN-COS-TAN-ATN?: Return for the first two takes all of memory and the full width, and Y keeps the functions.
  • The Model 33 has capitals only, which is all BASIC reads. Backspace sends RUBOUT, which BASIC echoes between backslashes as it deletes; @ throws the line away.
  • The switches are clicked above or below their pivot. STOP halts the machine, SINGLE STEP runs one instruction, EXAMINE shows the byte at the address the sixteen toggles set and EXAMINE NEXT the one after it, and DEPOSIT writes the low eight toggles there. RESET is the 8080's reset line, which sends it to address 0 and leaves STOP/RUN as it was.
  • A15 to A8 are the sense switches too, which INP(255) reads.
